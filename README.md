# Dwarpal OS 🛡️🤖
### Enterprise-Grade, Secure, Autonomous AI Analytics SaaS Platform

Dwarpal OS is a production-ready, highly secure natural language-to-SQL business intelligence platform.

## 🚀 Key Features
- **Natural Language to SQL**: Powered by Google Gemini (gemini-3.8-flash) for precise query generation.
- **Autonomous Self-Correction**: Catches database errors, self-corrects SQL, and retries automatically.
- **Database Guardrails**: Permits only SELECT operations and blocks destructive commands.
- **PII Redaction Guard**: Masks sensitive data like emails and phone numbers before rendering.
- **Interactive Visualizations**: Dynamic chart routing using Recharts.

## 🛠️ Tech Stack
- **Frontend**: Next.js, Tailwind CSS, Recharts
- **Backend**: FastAPI, Pydantic, Psycopg
- **Database**: PostgreSQL on Neon DB
- **AI Model**: Google Gemini API
